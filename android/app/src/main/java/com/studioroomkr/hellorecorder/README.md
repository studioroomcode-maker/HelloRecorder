# HelloRecorder — 절전형 상시 녹음 앱

소리가 감지될 때만 저장하고, 1시간 단위로 파일을 나누며, 설정한 보관 기간(기본 48시간)
뒤 자동 삭제하는 안드로이드 백그라운드 녹음 앱입니다.

## 동작 구조

```
AudioRecord (16kHz mono PCM, 항상 가볍게 캡처)
   │
   ├─ 녹음 허용 시간대 밖이면 → 인코딩 안 함, 1초 대기 (절전)
   │
   ├─ 버퍼마다 RMS(음량) 계산 → 임계값(슬라이더로 조정) 이상이면 "소리 있음"
   │
   ├─ 소리 있음 → WakeLock 획득 + AAC 인코딩 → 일별 폴더의 .m4a 기록
   │
   └─ 무음 2초 지속 → 인코딩 정지 + WakeLock 해제 (CPU 휴식)

별도: WorkManager 가 6시간마다 48시간 지난 파일 삭제 (보호 파일 제외)
재부팅: BootReceiver 가 마지막에 켜둔 상태면 서비스 자동 재시작
```

## 파일 구성

- `AudioEngine.kt` — 음성 감지 + AAC 인코딩 핵심 엔진 (음량 보고, 공간 확보 포함)
- `RecordingService.kt` — 백그라운드 유지용 포그라운드 서비스
- `CleanupWorker.kt` — 48시간 지난 파일 삭제 (보호 제외, 빈 폴더 정리)
- `BootReceiver.kt` — 재부팅 시 서비스 자동 재시작
- `Storage.kt` — 일별 폴더 구조 + 저장공간 관리/확보
- `Player.kt` — 파일 재생 (속도 조절·seek·위치 조회)
- `PlayerActivity.kt` — 재생 화면 (진행바·속도·북마크·구간 잘라내기)
- `AudioEditor.kt` — 무손실 구간 잘라내기 (MediaExtractor+MediaMuxer)
- `Share.kt` — 파일 공유 / 다중 백업 내보내기 (FileProvider)
- `Prefs.kt` — 모든 설정·상태 저장 (임계값/보호/시간대/품질/잠금/라벨/음량)
- `MainActivity.kt` — 전체 UI (설정, 음량 미터, 목록·재생·공유·삭제·라벨·검색)
- `AndroidManifest.xml` — 권한 및 서비스/리시버/프로바이더 선언
- `file_paths.xml` — FileProvider 경로 (res/xml/ 에 배치)

## 폴더 구조

```
filesDir/recordings/
  20260616/
    20260616_06.m4a
    20260616_14.m4a
    20260616_14_2.m4a   ← 같은 시간대에 끊겼다 다시 녹음된 경우
  20260617/
    ...
```

날짜별 폴더로 묶여 목록·삭제·탐색이 깔끔합니다. 비어 버린 날짜 폴더는
CleanupWorker 가 정리합니다.

## 적용 방법

1. Android Studio 에서 빈 프로젝트(Empty Activity, Kotlin) 생성
2. 패키지명은 `com.studioroomkr.hellorecorder` 로 맞춰져 있습니다
   (프로젝트 생성 시 Package name 을 동일하게 지정)
3. 위 .kt 파일들을 `app/src/main/java/.../` 아래에 복사
4. `AndroidManifest.xml` 내용을 본인 매니페스트에 병합
5. `app/build.gradle` 의 dependencies 에 추가:

```gradle
dependencies {
    implementation "androidx.appcompat:appcompat:1.7.0"
    implementation "androidx.work:work-runtime-ktx:2.9.1"
    implementation "androidx.biometric:biometric:1.1.0"   // 앱 잠금
    implementation "org.osmdroid:osmdroid-android:6.1.18" // 지도에서 구역 지정(위치 기반 녹음)
}
```

> 지도(osmdroid)는 Google Play Services / API 키가 필요 없습니다. 타일 로딩에 인터넷만 사용하며,
> `INTERNET`·`ACCESS_NETWORK_STATE` 권한이 매니페스트에 포함돼 있습니다.

추가로 `file_paths.xml` 을 `app/src/main/res/xml/file_paths.xml` 에 두어야
공유 기능(FileProvider)이 동작합니다.

6. `compileSdk`, `targetSdk` 는 34 이상 권장 (Android 14 마이크 서비스 타입)
7. 실제 기기에서 실행 (에뮬레이터는 마이크 동작이 제한적)

## 주요 기능

### 무음 기준(임계값) — 실시간 슬라이더
메인 화면 슬라이더로 50~3000 범위 조정. AudioEngine 이 매 버퍼마다
저장된 값을 다시 읽으므로 녹음 중에도 즉시 반영. 낮을수록 민감, 높을수록 둔감.

### 녹음 시간대 (알람식)
요일별·날짜별로 시작/종료 시각을 분 단위(알람처럼)로 지정. 각 요일은 체크로
on/off, 시작=끝이면 24시간 녹음. 특정 날짜를 추가하면 그 날은 요일 설정보다
우선 적용(예: 회의 있는 날만 따로). 시작 > 종료(예: 22:00~06:00)면 자정을 넘는
야간 구간. 시간대 밖에서는 인코딩을 멈추고 1초 간격 대기만 하므로 배터리 소모가
거의 없음.

### 자동 삭제 보관 기간
저장공간 설정에서 1시간~30일 사이로 조절(기본 48시간). 이 기간이 지난 파일은
CleanupWorker 가 자동 삭제(보호 파일 제외).

### 파일 목록 + 재생
상단 **‘파일’ 탭**에서 날짜별로 묶여 표시. 각 줄에 **재생 길이(듀레이션)**·용량·시각 표시.
▶ 버튼으로 재생. 왼쪽 체크로 여러 개 선택 → **전체 선택/해제, 선택 삭제, 선택 보관/보관 해제**
일괄 처리. 화면을 벗어나면 재생 자동 정지.

### 파일 보호 (자동 삭제 방지)
각 파일의 "보호" 체크박스를 켜면 48시간이 지나도 삭제되지 않음.
보호 키는 "날짜폴더/파일명" 상대경로 기준으로 저장.

### 재부팅 자동 재시작
마지막에 "녹음 시작"을 눌러둔 상태(Prefs 플래그)라면, 재부팅 후
BootReceiver 가 서비스를 자동으로 다시 켬.

### 저장공간 안전장치
설정한 "최소 확보 공간"보다 기기 여유가 적어지면, 새 녹음 시작 직전에
보호 안 된 가장 오래된 파일부터 자동으로 비워 폰이 꽉 차는 것을 방지.
화면에서 현재 사용량/여유 공간도 표시.

### 녹음 상태(음량) 실시간 표시
엔진이 현재 음량과 캡처 여부를 보고하고, 화면 상단 막대로 표시.
"🔴 녹음 중 / ⚪ 대기 중" 으로 임계값을 직관적으로 맞출 수 있음.

### 파일 공유/내보내기
각 파일의 "공유" 버튼 → 카톡·드라이브·메일 등으로 전송 (FileProvider).

### 파일 삭제·라벨
"삭제" 버튼으로 개별 삭제(확인 후), "라벨" 버튼으로 메모 부착.
라벨은 검색 대상이 됨.

### 검색·필터
파일명·라벨·날짜로 실시간 검색.

### 앱 잠금
"앱 잠금" 체크 시 진입할 때 지문/PIN 인증(BiometricPrompt).
기기에 인증 수단이 없으면 잠금이 자동 해제되어 못 들어가는 상황을 방지.

### 요일별 시간대
"주말을 따로 설정" 체크 시 평일/주말 녹음 시간대를 분리 지정.

### 녹음 품질 선택
16/32/64/128kbps 중 선택. 다음 녹음부터 적용.

### 재생 화면 (파일 ▶ 누르면 진입)
- 진행바로 원하는 위치로 이동(seek), 현재/전체 시간 표시
- 재생 속도 0.5 / 1.0 / 1.5 / 2.0 배 (긴 녹음 빠르게 훑기)

### 북마크 (중요 지점 표시)
재생 중 "현재 위치 북마크" → 그 지점이 ms 단위로 저장됨.
북마크 목록에서 ▶ 누르면 그 지점으로 바로 점프. 목록에는 📌개수로 표시.

### 구간 잘라내기 (편집)
재생 위치를 시작/끝점으로 지정 → "이 구간만 저장"으로 새 m4a 생성.
MediaExtractor+MediaMuxer 기반이라 재인코딩 없이 무손실. 원본은 보존됨.
※ 페이드·합치기 같은 정밀 편집은 FFmpeg 영역이라 포함하지 않음.

### 백업 내보내기
"보호한 파일 백업 내보내기" → 보호 표시된 파일을 한 번에 공유 시트로 전송.
구글 드라이브 앱을 고르면 일괄 업로드됨.
※ 완전 자동(무인) 클라우드 백업은 Drive API/OAuth 설정이 별도로 필요.

## 조정 포인트

대부분 코드가 아니라 **앱 화면에서** 조정합니다.

- **무음 기준(임계값)** · **구간 묶기 간격**(무음 N초 넘으면 새 파일로 분리) — ‘녹음 감도’ 섹션 슬라이더.
  간격을 길게 잡으면 짧은 침묵으로 끊긴 구간을 한 파일로 묶어 파일 수가 줄어듭니다(중간 무음은 저장 안 함).
- **녹음 품질(비트레이트)** — ‘녹음 품질’ 섹션.
- **녹음 시간대 / 위치 / 보관 기간** — 각 섹션에서 조정.

## 꼭 알아둘 현실적 한계

1. **제조사 배터리 최적화**: 삼성/샤오미 등은 백그라운드 서비스를 죽입니다.
   "배터리 최적화 제외" 버튼 + 기기 설정에서 직접 "제한 없음" 권장.
   일부 기기는 재부팅 자동 시작도 별도 허용이 필요합니다.
2. **저장 위치**: 앱 내부저장소. 다른 앱에서 접근하려면 MediaStore 로 변경 필요.
3. **법적 문제**: 동의 없는 녹음은 지역에 따라 불법일 수 있습니다. 용도 확인 필수.
