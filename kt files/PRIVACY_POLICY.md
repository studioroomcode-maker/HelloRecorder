## 1. 개요
HelloRecorder(이하 "앱")는 사용자가 직접 자신의 음성·주변 소리를 녹음·관리하기 위한 앱입니다.
본 방침은 앱이 어떤 데이터를 사용하고 어떻게 처리하는지 설명합니다.

## 2. 수집·사용하는 데이터

### 가. 오디오(마이크)
- **용도:** 사용자가 녹음을 시작하면, 설정한 기준(음량) 이상의 소리가 감지될 때 음성을 녹음합니다.
  화면이 꺼져 있거나 다른 앱을 사용하는 동안에도(백그라운드) 동작할 수 있으며, 녹음 중에는
  상태 표시 알림이 계속 표시됩니다.
- **저장 위치:** 녹음 파일은 **사용자 기기 내부 저장소에만** 저장됩니다.
- **전송 여부:** 외부 서버로 전송하지 않습니다.

### 나. 위치 (선택 기능)
- **용도:** 사용자가 ‘위치 기반 녹음’ 기능을 켠 경우에 한해, 지정한 장소의 반경 안/밖을 판단하여
  녹음을 자동으로 켜고 끄기 위해 기기 위치를 사용합니다.
- **사용 중에만(while-in-use):** 위치는 **앱을 사용하는 동안에만** 확인하며, **백그라운드 위치는 사용하지 않습니다.**
- 이 기능을 사용하지 않으면 위치 정보는 **수집되지 않습니다.**
- 위치 좌표(중심 구역)는 기기 내부에만 저장되며 외부로 전송하지 않습니다.

### 다. 전사(받아쓰기) 결과 — 선택 기능
- **용도:** ‘말한 내용으로 검색’ 기능을 켜면, 녹음 파일의 음성을 텍스트로 옮겨 검색에 사용합니다.
- **처리 위치:** 전사는 **기기 안에서만** 수행됩니다(온디바이스 STT). 오디오를 어디로도 보내지 않습니다.
- **저장 위치:** 전사 결과와 검색 색인은 기기 내부에만 저장됩니다.
- 이 기능에 필요한 음성인식 모델 파일은 인터넷에서 내려받습니다(아래 5항 참조).

### 라. 오류 진단 기록
- **용도:** 앱이 예기치 않게 종료되면 원인 파악을 위해 오류 상세(오류 메시지와 발생 위치),
  앱 버전, 기기 모델, 안드로이드 버전을 기록합니다.
- **저장 위치:** 기기 내부에만 저장되며, 개발자나 제3자에게 **전송되지 않습니다.**
  녹음 오디오나 전사 내용은 포함되지 않습니다.
- **보관·삭제:** 최근 기록만 보관되며(오래된 것부터 자동 삭제), 설정에서 직접 지우거나
  개발자에게 보낼지 사용자가 선택할 수 있습니다.

### 마. 수집하지 않는 것
- 계정·이름·이메일·전화번호 등 개인 식별 정보를 수집하지 않습니다.
- 광고 식별자나 분석(애널리틱스) 데이터를 수집하지 않습니다.

## 3. 데이터 보관 및 삭제
- 모든 녹음 파일과 설정은 **사용자 기기 내부에만** 저장됩니다.
- 녹음 파일은 사용자가 설정한 보관 기간(기본 48시간, 조절 가능)이 지나면 자동 삭제됩니다
  (‘보관’ 표시한 파일 제외).
- 사용자는 앱 내에서 파일을 직접 삭제할 수 있으며, 앱을 삭제하면 모든 데이터가 제거됩니다.

## 4. 제3자 제공·공유
- 개발자는 서버를 운영하지 않습니다. 녹음 오디오, 전사 결과, 녹음 장소 설정을 개발자나 제3자에게
  판매·공유·전송하지 않습니다.
- 사용자가 ‘공유/내보내기’ 기능으로 직접 선택해 다른 앱(메일, 드라이브 등)으로 보내는 경우에만
  해당 파일이 사용자의 의사에 따라 외부로 전달됩니다.
- 다만 아래 5항의 선택 기능을 사용하면, 그 기능에 필요한 범위에서 제3자 서비스와 네트워크 통신이
  발생합니다(녹음 내용은 포함되지 않습니다).

## 5. 제3자 서비스와의 통신 (선택 기능 사용 시)
아래 기능을 사용할 때만 인터넷 통신이 일어납니다. 어느 경우에도 녹음 오디오와 전사 결과는 전송되지 않습니다.

- **지도(OpenStreetMap):** ‘위치 기반 녹음’의 지도 화면은 OpenStreetMap(osmdroid) 타일을 사용하며,
  지도를 표시하기 위해 인터넷으로 타일 이미지를 내려받습니다. 이때 **보고 있는 지도 영역의 타일 좌표**가
  타일 서버에 전달됩니다(현재 위치 주변으로 지도를 열면 그 주변 영역이 됩니다).
  저장된 녹음 장소 좌표 자체를 전송하지는 않습니다.
- **음성인식 모델 다운로드(Hugging Face):** ‘말한 내용으로 검색’을 켤 때 모델 파일(약 76MB)을
  Hugging Face 에서 내려받습니다. 다운로드 요청 외의 사용자 데이터는 보내지 않습니다.
- **결제(Google Play 결제):** Pro 구매·복원은 Google Play 결제를 통해 처리되며, 결제 정보는
  Google 이 처리합니다. 개발자는 사용자의 결제 수단 정보를 받지 않습니다.
- 위 서비스들의 데이터 처리에는 각 제공자의 방침이 적용됩니다.

## 6. 권한 사용 요약
- **마이크(RECORD_AUDIO):** 녹음.
- **위치(ACCESS_FINE/COARSE_LOCATION, 사용 중에만):** 위치 기반 녹음(선택). 백그라운드 위치는 사용하지 않음.
- **알림(POST_NOTIFICATIONS)·포그라운드 서비스:** 백그라운드 녹음 유지 및 상태 표시.
- **인터넷:** 지도 타일 다운로드(위치 기능 사용 시), 음성인식 모델 다운로드(‘말한 내용으로 검색’ 사용 시),
  Google Play 결제(Pro 구매·복원 시). 녹음·전사 데이터 업로드에는 사용하지 않습니다.
- **부팅 시 실행(RECEIVE_BOOT_COMPLETED):** 재부팅 후 녹음 자동 재개(사용자가 켜 둔 경우).
